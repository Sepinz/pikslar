Pikslar guide

For Pikslar 0.9.0 beta. This is a test version: keep copies of any artwork you care about, and save beta work in a folder of its own.

Requirements

  • Windows 11, or Windows 10 version 1703 or later, 64-bit (x64). Pikslar has been tested on Windows 11 only; Windows 10 has not been tried yet. Older Windows cannot start it.
  • No installation, administrator rights or internet connection. Pikslar has no network code at all.
  • Not signed yet, so Windows SmartScreen warns the first time it starts. Where Smart App Control is on, unsigned programs cannot run; do not turn it off for Pikslar.

Build and run

There is no public download yet. To build from source you need Rust for the x86_64-pc-windows-gnu target and a MinGW-w64 linker.

cargo run --release -p pikslar

The release package (the editor, pikslar-cli.exe and the documents that go with them) is made reproducibly by spikes/make-release.ps1, which pins the toolchain and linker versions it accepts; docs/b1-packaging.md in the repository explains it.

First steps

  1. Start pikslar.exe. It opens an empty canvas; Ctrl+N makes a new one of the size you choose.
  2. Draw with the pencil (B). Right-drag erases, Alt+click picks a colour, the wheel zooms and Space-drag pans.
  3. Add frames with N, turn on onion skin with O and play with Enter.
  4. Save the project with Ctrl+S. The status bar says "Saved" only once the file is in place and has been read back.
  5. Export with Ctrl+E for a frame or Ctrl+Shift+E for a sprite sheet.

The menus list every command with its shortcut, and View, Keyboard shortcuts lets you change them.

What Pikslar writes

Projects and exports go only where you choose. While saving it may briefly write name.piks.pikslar-tmp and name.piks.pikslar-bak beside the project; both are removed when the save ends. Everything else is in %LOCALAPPDATA%\Pikslar\: settings, a recovery copy of unsaved work, Rewind history if you turn it on, a small saving log and short crash notes. The log and notes never hold artwork, document content or anything you type, and can be turned off and deleted from the View menu. Pikslar writes nothing to the registry and nothing beside pikslar.exe.

To remove everything, delete the Pikslar folder and %LOCALAPPDATA%\Pikslar. Your projects stay where you saved them.

Command line

CommandDoes
pikslar.exe drawing.piksOpens a project, a PNG, or an Aseprite file (read only)
pikslar.exe --versionPrints the version without opening a window
pikslar.exe --no-settingsReads and writes no settings this time
pikslar.exe --scale NForces the interface size, 1 to 4
pikslar-cli.exe --helpExport, palettes and batch scripts without the window

Problems and reports

The release package includes KNOWN-ISSUES.txt and TROUBLESHOOTING.txt, which explain what is known to be missing or untested and how to send a report.

Problems can also be reported as issues on GitHub.
